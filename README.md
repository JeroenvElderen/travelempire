# TravelEmpire — WorldFront 2.0

Worldwide, single-player taxi company management simulator.

## Development

This project uses Vite, React, TypeScript, MapLibre GL and a modular simulation architecture. The first milestone focuses on a reliable mobile-first interface and a local demonstration map. Server-authoritative operations, authentication, cloud persistence, routing and financial ledger will be introduced as separate tested milestones.

See `docs/architecture.md` for design boundaries.
